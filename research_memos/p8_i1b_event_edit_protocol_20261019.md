# P8-I / I1b：局部操作配对与伪影控制协议（设计，未执行）

**目的**：落实用户“Noisy局部可辨识性”的第一阶段数据准备；不是开发新的增强器。I0已完成文件登记，I1a已完成配对/残差审计；本文件是下一步的**设计决定**，不授权真实选区、编辑/混音、输出音频、前端/后端推理、D0–D4训练或性能评测。

## 1. I1a对下一步的实际约束

I1a的12对都在冻结±10ms范围取得zero-lag最大相关，独立数值重建通过；不据此证明录音无任何处理、噪声纯净或内容可辨。保持原始zero-lag、gain1，不使用每句拟合gain，不删除p239_028；原metrics SHA `93af91ade77fd6072b40a7e8ef915edf360dc4748f4223eca15287aa1d6a08a6`。source registry SHA `817c6f7ef5450366fcf8d146675c761df4c17abcdf419f3bb8fd4c6a4aad7ee6`。

这里Nraw=X−S只是物理坐标下的**候选残差**。不能各给unknown残差一个独立录音ID；当前不跨句搬运残差、不重新定标噪声或合成新SNR、不冻结noise-disjoint训练split。用户所提多来源噪声/多SNR及最终D0–D4仍属于后续完整范围，未被本技术阶段替代；需独立来源和执行设计。

## 2. 先把估计问题写准确

本阶段唯一操作标签是 `original / local_attenuation / sham`。不能标成 `speech_absent / fake_phoneme / k / s / hallucination`。自动选区也不是可信音素边界。

**成功终点仅为配对来源、选区、mask、算术和最终表示的可重现性**，不包含操作分类准确率。即使将来操作分类AUC很高，也可能只辨别局部能量下降、编辑痕迹或样本来源，不自动回答“原Noisy支持哪个真实声学事件”。本阶段通过不会自动授权训练操作检测器或宣称CAEG成立。

## 3. 最小候选选区（后续实现前需单独冻结完整算法）

- 仅I0原12句/6speaker，各句至多2个候选：一类Clean局部高频正谱变化，一类Clean持续高频结构。使用同一固定分析窗/频带/采样网格，只看Clean，不跑Y_pre、不看StoRM/识别器输出挑区域。
- 候选最多24个；同句窗口互不重叠且预先留边界间隔。自动选区可触及摩擦样、瞬态、元音谐波或底噪，故仅使用描述类名，不叫已经证实的“弱辅音”。必须记录实际能量、duration和选择分数；零能量或算法无定义记unavailable，不以另一句或放宽规则补数。
- 本协议先定**作用窗80ms=1280样本、两端10ms=160样本**，全部事件相同长度；候选算法的STFT、排名、中心定位、非重叠及tie规则尚需写成冻结config。未冻结前不读取真实Clean来试选、也不边看选区边调频带/阈值。
- 这是Clean-oracle定位，未来若D0只收到该crop，其结果必须标注定位优势；不能当部署事件定位。未来D0–D3需匹配有效上下文，F(X_h)逐臂对应，不能给H0偷用H1隐藏特征。

## 4. 操作与位置对照

对已冻结目标窗T，令m_T∈[0,1]，支撑严格限于T。中心衰减至原幅度0.25，令d_T=−0.75m_TS：

```text
原始臂：S1=S, X1=X  （文件逐字节复制，真实原观测）
削弱臂：S0=S+d_T, X0=X+d_T
候选残差：Nraw=X−S，对两臂相同
sham：走相同元数据/调度但不做非零编辑；输出仍复制原文件字节
```

H0可能因Nraw泄漏仍含目标结构；因此只称“削弱”，不称音素不存在。`S0+Nraw=X0`只是浮点算术一致性。固定衰减0.25不是参数搜索，也不声称具有科学最优性。

对照窗C从同句且不与T重叠的位置选，按Clean扰动L2最接近的固定规则排序；精确规则与tie在config阶段再冻。**C叫位置对照，不叫负例/非语音/无事件区域**，它完全可能含语音。相同操作在C产生d_C与对应X_C，报告L2及谱/包络失配，不能因能量接近就声称编辑可检测性匹配。

未来若做target-vs-control分析，T/C都保留各自未编辑与真实编辑臂，不能把“是否发生编辑”直接编码目标类别；它们的未编辑波形同为X，应作为同源重复而非独立样本计数。sham只检查零操作实现，不是有效排除实际编辑伪影的科学对照。

预设两类边缘算子：余弦与线性taper，端点均为0、plateau为1、全长一致；未来完整config须明确离散索引。两种算子用于检测实现/编辑依赖性，不是两套自然发音。它们都可能引入可学习痕迹；若效果仅随某个算子或能量差走，不能通过换算子找有利结果，需保留并停止相应内容主张。

## 5. 表示与不可变性

- 内部全部float64，原int16/32768，不逐臂peak归一化、不去DC、不调整gain/lag；mask外S/X逐样本不变。以后若导出，Clean/Noisy/编辑版本共同使用事先固定的PCM16规则，不能对不同标签用不同序列化方式。
- 原臂与sham复制原WAV字节并独立SHA，不能经过重编码后仍称byte-identical。任何数组供探针时应统一解码/存储路径，操作者侧car/文件名/标签/mask及另一成对Noisy不能成为输入。
- 对编辑臂分别记录：float64重构误差、预量化越界计数/峰值、量化误差、量化后重构误差及mask外一致性。**不能静默clip或逐臂归一化解决越界**；出现越界保留该行失败状态，不另换样本，不导出被clip的版本。
- 量化后不要求独立量化S0/Nraw/X0仍保持精确加法；允许误差由冻结量化算术推导，不能拿float域等式替代PCM域验证。原始数据、I0/I1a指标/来源与有效checkpoint均只读。

## 7. 停止条件

无法定义独立于输出结果的选区/对照、需要挑窗或改衰减才让样本“合理”、依靠noise伪ID制造split、实际只能识别编辑痕迹、或企图用操作准确率替代真实声学内容时，不扩大/不开训。该结论也不能反向证明自然Noisy绝对无信息。

**本协议保留原科研目标**：准备可信数据是为了后续判断真实信息是否被前端/后端丢失，而不是将“检测一个人为幅度编辑”包装成增强创新或弱辅音恢复。
