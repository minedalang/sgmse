# P8-V 材料门：本地来源与候选标注审计

**结论：已有材料支持名义辅音竞争的准备，但尚未组成完整 P8-V 验证集。** 这不是“没有任何数据”，也不是继续复跑旧样本的理由。审计范围和逐文件哈希见同名 `.json`；仅标准库读取清单、文档与44份 corpus-train 源 WAV 的字节哈希，不解码音频样本。零网络、模型、重采样、训练和新音频。

## 2. 重要的使用历史修正

不能只减去两个主实验各4位 speaker，便说还剩8位“未用过”。原clean校准还包含12份补充录音，涉及额外speaker；两个已缓存源清单的 speaker 并集实际为13位。

相对**这两个已缓存源清单**，只剩 `f13 / f24 / m17` 未出现在其中。它们在 archive inventory 的音频项数依次为415/407/419，同上下文/stress的 kgtd 完整组16/15/17。**本轮未选定其中任何录音，未创建 split、未取回音频；也未完成全项目使用史或预训练暴露审计，不能直接称三位为独立 holdout。** 这些组数不是独立 speaker 样本数。

这说明：不能将未来 train/calibration/confirmation 分别塞给这三位 speaker，就声称做出了稳定跨 speaker 泛化。若用于极小可行性试验，必须事先限定结论强度，不能用三位 speaker 支持总体可靠性区间。

## 3. 还缺的不是另一次 ASR

1. **缺失事件对照**：24种名义辅音不是“事件不存在”类别。MLF 中的 `sil` 是分段标签，不是相同语境下整条无目标候选录音。删除 clean 窗口可以成为明确标记的合成操作，但不能直接冒充自然缺失真值或无拼接捷径的反事实。
2. **部署候选来源**：当前没有冻结的 proposal policy，不能保证真实身份进入候选。把原始 clean 配对放入候选仅是 oracle 诊断，不能作为部署恢复。
3. **拒答与校准**：现有真转写/名义身份不提供“该 noisy 对人耳不可辨”的标签；听者可辨性、reference身份和模型拒答仍应分列。不存在现成的三态校准集与波形回退规则。
4. **独立确认材料**：旧VCV、5243、VoiceBank四句与B开头均已分析。未使用的清单成员不等于无预训练重叠，取回前也不能称通过实际录音质量与身份审核。

## 4. Lead 决策：不要把门设成不可能，也不要假装已过门

**不要求自然录音提供物理上完全相同的反事实波形。** 可接受相匹配但不同录音的声学假设，只是必须把相位、时长、共发音和说话人线索当 nuisance；白化波形残差基线不适合的情况也要如实标记。首个局部可行性试验可只检验近音身份判别，但它不是完整存在/缺失验证，更不能改称已完成最终内容恢复目标。

下一步优先级：

- **首选：补来源方案，不加模型。** 比较可追溯的新材料/标注方案，明确近音、缺失、候选集外和校准/确认分别由什么证据提供，以及是否需要新许可/下载/人工标注。只找额外 ASR 不能补这些缺项。
- **条件性小试验：** 若材料与使用史审核通过，再单独冻结一个身份竞争正控制；包含候选先验与简单残差/表征基线，固定噪声，区分“候选没有真值”与“验证器拒错”。不使用旧四句/五例替代确认集。
- **暂不做：** 训练 verifier、把拒答译成静音、向 OUVE 加梯度/改中心、重复旧VCV增强、追加B开头窗口或新ASR。Gate A 当前的失败是准备条件未齐，不是算法无效的实验结果。

本轮证据让下一步从“假定已有现成反事实训练集”改为“先确定缺失/近音与部署候选的来源”。方法仍可替换或放弃；不能为了保住 P8-V 名字不断把监督要求缩窄。
