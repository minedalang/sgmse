# P8-I / D4：理想检测参照的计算合同与缺项

**状态：解析/来源审查，未运行实际D4检测性能评测。** 不训练、不拟合噪声模型、不读取音频、不向已关闭I1b追加性能搜索。D0–D4及CAEG的原范围保留，本文不以一个易算Gaussian公式替代真实可辨识性验证。

## 1. D4真正需要的输入

用户提案中的D4是**指定候选、指定噪声模型下**的理想参照。至少应冻结：

1. 两个固定声学候选S0/S1的真实坐标/幅度/长度，δ=S1−S0；不从被评分的噪声观测反选候选来获得有利分差。
2. 共同噪声均值m与正定协方差Σ，或有来源、独立校准的估计规则；协方差是跨重复观测的分布性质，不是单条残差的别名。
3. 假设先验、误判代价或指定FPR；候选时延/gain/身份未知时须明确如何处理这些nuisance，不能逐候选用Clean拟合后冒充固定模板。
4. 评价域与统计单位：实波形或有正确协方差的线性表示，不把压缩谱差当物理噪声，不把冗余STFT bin当独立样本多算证据。

当前I1a/I1b有可复现波形/操作与能量统计，但noise来源/纯度unknown，没有经验证的Σ或噪声分布。因此**不能直接把delta_energy/residual_power填成现实D4成绩**。如未来算白噪声假设敏感性，只能另批为有假设的解析参照，不宣称实际准确率/上下界；本轮没有做这种逐例计算。

## 2. 等协方差Gaussian下的精确关系

条件：X=S_h+N，N~N(m,Σ)，Σ正定且两H共享；候选、m、Σ已知。令d²=δᵀΣ⁻¹δ，d=√d²。对数似然比可写为

```text
T(X) = δᵀΣ⁻¹ [ X − m − (S0+S1)/2 ]
T | H1 ~ Normal(+d²/2, d²)
T | H0 ~ Normal(−d²/2, d²)
```

这与等协方差线性判别展开一致，参照 [Stanford STATS202 LDA原始讲义](https://web.stanford.edu/class/stats202/notes/Classification/LDA.html)。匹配滤波与Gaussian尾概率的标准背景见 [MIT6.011 Lecture24](https://www.ocw.mit.edu/courses/6-011-signals-systems-and-inference-spring-2018/dfe2855f36e44436678bfd3736c937fe_MIT6_011S18lec24.pdf)。下式由上述两个标量分布直接推导，不是本项目的新方法：

```text
d>0、equal prior / equal cost：Pe = Φ(−d/2)
对LLR排序：AUC = Φ(d/√2)
指定0<f<1的FPR：TPR = Φ(d + Φ⁻¹(f))
```

非等prior/cost需要改变阈值，不能沿用equal-prior准确率。若m未知却直接置0，所写均值/零阈值规则不再有保证。d=0时T恒0，错误率与按平分ties定义的AUC均1/2；任意指定FPR需随机化ties，此时TPR=f。不要用epsilon把退化情况伪装成有限检测能力。

## 3. 同样的噪声总能量，可以有不同的检测难度

**二维解析反例，不是实际语音检测结果**：δ=(1,0)，共同均值0，两个可选模型

```text
ΣA = diag(1/4,7/4), trace=2 => dA²=4
ΣB = diag(7/4,1/4), trace=2 => dB²=4/7
```

两模型噪声总方差相同，δ能量也相同，但equal-prior错误率分别约0.15866和0.35273。Root用Fraction核对精确分数、erfc核对两种假设下的尾概率，未抽样/拟合/读音频。这个反例只证明**标量噪声能量不足以唯一确定D4**，不证明本机真实噪声属于任一模型。

更一般地，固定trace也不限制噪声在δ方向的分配；白噪声假设不自动是现实colored noise的保守界或乐观界。因此现有I1a全句残差RMS、I1b局部delta能量即使都精确，也不能补上方向协方差的缺项。观测残差样本的平均能量本身也没有自动等于真实population trace。

## 4. 估计误差的可报告方式，不是用正则化生成保证

若未来有独立依据证明0<α≤β且

```text
αΣ0 ≼ Σtrue ≼ βΣ0
```

则逆矩阵Loewner序给出

```text
d0²/β ≤ dtrue² ≤ d0²/α,  d0²=δᵀΣ0⁻¹δ
```

该界依赖包络**真实成立**及上述共享Gaussian模型；不能从残差RMS或shrinkage参数自行推出。将Σ+λI变成可逆只是改变/正则化模型，不意味着估计已校准。有限样本、重叠帧、语音泄漏及非平稳noise须保留，不能将模型预测FPR直接当观测FPR。

奇异Σ应单独检查支持空间：若δ有噪声零空间分量，两H支持可能分离；简单pinv会忽略该分量。若实施版仅支持SPD，应明确拒绝奇异输入，而非静默pinv或加epsilon再报告完美检测。
