# P8-V / V0a：候选声学证据审查的可辨识性与最小反证

**状态：方法审计完成，算法有效性与新颖性未成立；不授权 V1/V2。**
这是 Research Lead 的数学分析和定向文献核对，不是新增声学实验。没有运行增强、ASR、训练、真实音频解码或新候选生成。只读查新有网络访问，未计量请求/字节，不能写成“零网络”。现有 VoiceBank、VCV、5243 和 B 开头实验维持关闭。

## 1. 决策摘要

保留“候选特异、可双向否决、允许拒答”的问题定义，但不把它当已发现的算法贡献。进入任何模型实验前，先解决三个缺口：

1. **候选覆盖**：真实事件没进入候选集时，排序不能恢复它；把 clean 当额外候选只能测试 oracle 上界，不能代表部署。
2. **证据可辨识性**：物理混入语音不等于身份可辨；比较两个坏候选也能得到很大的胜负分数。
3. **拒答的实现**：`unknown` 是审查状态，不是可播放音频。禁止把它默认译成静音或删掉弱辅音。首阶段只输出排序/拒答记录，不修改波形。

**当前推荐动作**：只读候选/标注来源可行性审计，找出是否有合法、未反复筛选、同语境可比较的存在/缺失/近音材料；若没有，明确报告数据门未过，不写 verifier 或改 OUVE。材料审计不是模型实验授权。

## 2. 定向先例核对（不是穷尽查新）

复用本地 `experiments/p8_evidence_prior_audit_20261019/papers/` 的固定版本原文及其检索记录；本轮重新浏览主要论文，并补读 StuPASE 方法段。以下仅总结方法，不移植其性能数字。

| 原始来源与核对位置 | 已覆盖空间 | 对 P8-V 的含义（本研究推断） |

| [ArtiFree v1，§3.1–3.2 / Algorithms 1–2](https://arxiv.org/html/2509.19495v1) | 多扩散样本的表征方差、中心性及 noisy 表征相关性选择 | “生成多个再筛选”已有直接先例；clean 相关选择在原文仅作分析 |

| [Grounded Decoding v1，§III-D–G，Eqs.32–45](https://arxiv.org/html/2609.04245v1) | 以 FSQ 距离惩罚候选；校准残差 SNR 调节锚定；局部邻域内再选 | 候选级 grounding 本身也已覆盖。可能差异只能落在可验证的事件身份/反证及拒答，而非命名 |
| [StuPASE v1，§2.2–2.3](https://arxiv.org/html/2603.09234v1) | dry-target 微调；净化音系表征与 noisy Mel 条件化 flow matching，再用 Mel vocoder 合成 | “语义/声学分工 + 生成质量 + 少幻觉”已有直接先例，不足以证明本项目创新 |

这些机制的不同不证明 P8-V 不存在先例。尤其不能因 Grounded Decoding 是离散自回归、StoRM 是连续扩散，就把应用载体变化当贡献。其 Eq.44 明确保留 anchor；不能把“有保留选项”单独宣称为本项目新机制。原文 §IV-B 的主要 WER 是 capped 句均，与本项目 uncapped 微 WER 不能直接数值比较。

**查新结论**：普通一致性、相关性重排、观测锚定、SSL 蒸馏及双流生成不足以立项。尚待查证/验证的是：在相匹配声学候选间，是否能学习超越简单物理残差基线的身份特异证据，并在恢复/错补两方向及拒答覆盖上泛化。这里是研究问题，不是已证实空白。

## 3. 数学审计：先把“似然”说清楚

以下为本轮推导，不是上述论文的实验结论。

令共享上下文为 C，两个固定、同尺度、同对齐的完整局部候选为 s0、s1，δ=s1−s0。若假设 N|C 为已知零均值 Gaussian，且两候选共享正定协方差 Σ、不依赖待评分 X，则：

```text
ell_i(X|C) = constant - 1/2 (X-s_i)^T Σ^-1 (X-s_i)
Δ = ell_1 - ell_0
  = δ^T Σ^-1 (X-s0) - 1/2 δ^T Σ^-1 δ
```

这就是白化后的匹配滤波/残差二次型比较，**不是新算法**。Σ=σ²I 时等价于比较平方残差；更复杂网络必须超过这个基线，不能只超过随机排序。候选引入的额外能量受到第二项惩罚，但未指定噪声模型时，“残差小”也可能选择把噪声抄进语音的候选。

在这两个简单 Gaussian 假设、等先验下，d²=δᵀΣ⁻¹δ，最优二分类错误率为 Φ(−d/2)。当 d 接近零时，即使理想验证器也接近猜测。对一般两分布，等先验 Bayes 错误率为 (1−TV(P0,P1))/2。它们只是理想界限，不能用全句 SNR 或旧 B 的能量/相关性替代 d 或 TV。

**实际不满足的条件**：真实候选相位/时长/幅度可能不匹配；噪声非平稳；Σ 未知；s_i 通常由同一个 X 自适应产生。此时上式最多是基线分数。若需要对增益/时移/噪声参数拟合，两个假设必须使用相同自由度、相同预注册范围；不能为其中一方单独优化。候选各自拟合协方差还需考虑归一化项，不能任意省略 log det。正式 composite likelihood 应积分 nuisance 或明确声明 profile approximation。

生成器和验证器共用 X **并非禁止**，但按固定外部假设推导的概率解释不再自动适用；增大候选数会增加选择乐观偏差。必须按最终候选生成流程、候选数和筛选规则另做独立校准，不能把固定候选上的阈值搬到任意多次采样。

## 4. 二选一不能代替真实内容判定

| 常见误推 | 必须额外记录 |
|---|---|
| s1 分数高，所以存在该辅音 | s0/s1 都错、近音竞争及候选集外真值；负分只支持指定 s0，不代表“没有语音” |
| Δ 近零，所以“没有信息” | 可能是两候选都好/都坏、模型无力或真正不可辨；不得混为一个人工真值 |
| 候选至少一个真实，故可恢复 | 部署流程是否真的能提出真候选；覆盖率需在完整 proposal set 上独立评估 |
| clean 原文可提供局部标签 | 词句转写不自动给辅音身份、时序/共发音或人工可辨边界；强制对齐也是模型估计 |
| 候选胜率提高，增强已改善 | 第一阶段只证明有条件排序；端到端真实恢复/误插入/音质还未测量 |

对一个“有正确身份候选”的二选一受控集，标签只描述参考内容身份。**不把低 SNR、模型置信度低、听者不知道或 clean 支撑为空任一单项直接当 unknown 真值**。报告参考身份、听者可辨性/分歧和模型拒答三个独立字段；候选集外/不合格候选单列，不强塞为 H0。

## 5. 最低成本的反证结构（设计要求，未冻结/未执行）

先做材料门，再写预注册配置。下列是三个顺序 gate，不是已批准运行的三项实验。

### Gate A：只读材料与候选覆盖审计

- 所有 split、使用历史、许可、原始身份和候选构造方式可追溯。独立指未参与本项目选择，不保证基础模型预训练未见。
- 相同说话人/语境的存在—缺失—近音候选有无真实可比较来源；自然最小对也不能假定时长、共发音、响度完全相同。
- 人工拼接候选不得混同自然候选，记录边缘、幅度、频谱/相位和生成器来源；不能把删除 clean 窗口形成的边缘当音素反证。
- 结论必须是可用/不可用和具体缺项；不得为了过门偷偷生成新音频、调用 aligner/TTS/ASR 或下载权重。

**成本**：标准库/文档读取，0 模型、0 真实音频解码、0 新波形；若需要超出该范围另列设计。没有身份合格材料则停止，不拿旧四句/五例凑确认集。

### Gate B：固定候选的证据分辨（未来需另批）

- 必须有存在/缺失及近音竞争，不只 speech/non-speech；同内容跨独立噪声、同噪声跨身份，候选次序随机且平衡。
- 基线至少含：候选/上下文先验（不看 X）、标量残差、共享噪声谱白化残差、部署可用的表征相关分数。oracle noise/clean 只作标明的诊断上界。
- 核心反证：只看候选能否同样获胜？同语境换身份时分数是否跟随 X 而非更自然候选？换噪声后是否仍有效？若预注册输入错配负控制，要承认其可能 OOD，不能单独证明因果机制。
- 评分至少分开 reference-present 的正确选择/误拒、reference-absent 的错误支持、近音替换、集外/拒答覆盖；检查候选顺序反转、同候选、共享缩放等基本性质。这些性质通过也不代表有效性。
- calibration 与确认 speaker/noise 不重叠；阈值不看确认集，按实际 proposal policy 校准，所有覆盖率含全拒与全选端点；按 source/speaker 聚类而非把噪声格当独立人。

**成功要求**：身份判别在相同覆盖率下优于最佳简单基线，且不是靠牺牲真实弱音召回；speaker 聚类区间/样本不足必须如实报告，不以一两个 speaker 给出稳定泛化结论。

**退出**：不看 X 的基线同样强、只识别候选拼接/幅度、噪声更换后失效、只在 oracle noise 下有效，或无法超过物理残差基线，则不进入波形改动。具体样本数/秒数/统计门尚未确定，不能据本段启动。

### Gate C：部署动作（B 通过后再设计）

先分离 proposal 覆盖与 selector 损失；受控 oracle 候选排序不能作为增强恢复结果。再比较相同总 NFE、候选数、encoder 调用及 wall-time 的 selector/no-selector；不能仅比较单次 StoRM。`unknown` 的回退选项需明确且经过独立内容/质量评价：保留 Y_pre 可能保留吞音，保留原生成也可能保留错补，两者均非免费安全解。

不在冻结 Score 上任意改 OUVE 中心，也不把未经匹配训练的 verifier 梯度相加视为合法采样。真正端到端结果须同时包含真实正确恢复、错误新增/替换、人耳可懂度、质量/身份/保真及预算；允许 Pareto 权衡但不能借静音或拒绝所有弱音伪造改善。
