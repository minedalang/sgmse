## 2. 精确分解与数值

每文件K=4，M为现存4个PCM波形的算术均值，仅在内存临时计算。对同一clean参考S：

```text
E_average = (1/K) sum mean((B_k-S)^2)
E_mean = mean((M-S)^2)
V4 = (1/K) sum mean((B_k-M)^2)
E_average = E_mean + V4
```

全部16文件恒等式复核，最大残差约6.78e-20；独立实现用pairwise平方差验证V4，不共享业务计算函数。

| 等文件、clean功率归一均值 | 数值 |
|---|---:|
| 四端点平均参考误差E_average | 0.249055739 |
| 四波形集合均值参考误差E_mean | 0.217425240 |
| seed间离散度V4 | 0.031630499 |
| pooled normalized V4 / E_average | 12.7002% |
| 各文件V4/E_average的均值 / 中位数 | 13.5674% / 13.0073% |
| 各文件比例范围 | 5.9540%–19.3003% |

所有16文件均由E_mean项大于V4项。pooled12.70%与mean13.57%不是同一个加权比率，不能挑大者叙事。其余87.30%是**有限四样本中心与参考的偏离项**，不是已经识别出的真实生成器偏差/幻觉比例。

若另假设4seed是相同条件生成分布的IID采样，则V_unbiased=4V4/3，bias2_est=E_mean−V_unbiased/4。该批归一均值分别0.042173999与0.206881740；全部raw bias估计非负，未做截零。它们依赖IID、固定参考与小样本，并不证明网络是正确posterior或bias估计有准确覆盖。

## 3. 哪个解释被削弱，哪个没有被证明

- 对**这批现存旧Router缓存**，“主要参考平方误差只是seed间随机变化”不符合有限集合分解：可由四样本平均去掉的部分约12.70%，大部分仍留在中心参考误差中。
- 这不说明随机变化无关紧要，更不能将结论直接移到VB OFF。时间/相位、共同残噪、共同失真、模型偏差、同一条件下真实多解等均可能影响中心误差；没有局部音素身份标签来分离它们。
- MSE较低的集合均值来自代数，不是验证了一个新的增强器。实际生成4份需历史120NFE/输入，较单次30NFE约4倍（未含任何选择/质量模型）；本轮仅复用缓存，不偷把其生成成本记为零成本新方法。
- 平均可能平滑细节，不承诺音质、身份或词句正确性。本轮没有输出平均音频，亦没有给它跑任何指标或试听。旧多轨迹selector已有结论/负结果不因这项分解被撤销或复活。

## 4. 下一方法门：别把方便的确定性输出错叫条件均值

前一轮VB方向几何只证明小正步的MSE空间；本轮又说明旧缓存的有限seed波动不是全部参考误差。两者共同反对“简单把随机性平均掉就完成内容与质量改善”的快捷路线，但**不能据此确定当前模型误差的因果分解**。

若未来设计控制试验，必须区分：

1. **真正的条件均值**E[S|X]与一个确定性函数。frontend、固定seed或把随机项关掉都不能直接宣称前者。
2. probability-flow ODE即使在精确score/正确初分布下保持相应边缘分布，也不等于给每个X返回其conditional mean；固定初态更不能凭名字叫MMSE估计。这里是方法审查要求，不新增ODE实验。
3. OUVE Tweedie反解出的x0_hat通常依赖当前随机状态z_t与X，是条件于z_t/X的均值型预测；单次读出不等于已对z_t积分后的E[S|X]。不把早一步或最后一步x0_hat自动定为“无偏差真语音”。

上述ODE边缘分布而非MMSE的区分对照了[Song等SDE论文v2的probability-flow框架](https://arxiv.org/html/2011.13456v2)；其同分布结论有精确score/适当数值极限等前提，本项目近似网络和N30不能直接继承精确保证。这里不宣称已运行ODE或其条件版本。

**优先顺序**：先查训练目标/推理读出究竟在估计哪个对象，再提出匹配NFE、EMA、输入和可信内容端点的新对照；若只能换seed/关噪声/平均后再搜最有利指标，就不执行。完整内容恢复、质量收益和计算成本仍须共同验证，不缩为单一MSE。

当前没有批准新的sampler、读出、训练、平均/selector或对关闭32格追加seed。可继续只读训练/推理估计对象审查；盲听未实施、听者资源未定，不伪造人工内容结论。
