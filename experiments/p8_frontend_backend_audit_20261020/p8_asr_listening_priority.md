# P8 听感优先级索引

该索引由同一个 Whisper `tiny.en` 对 clean、Y_pre、Router-off、Router 的中央 12 秒转写得到。clean 也是自动转写的伪参考，因此这里只用于安排听感顺序，不能作为人工 WER、内容保真或幻觉证据。

## 建议优先顺序

先听 **样本 5、3、6、2**：ASR 伪距离显示 Router 相对 Router-off 可能变差。
再听 **样本 1、4、7**：ASR 伪距离显示 Router 相对 Router-off 可能变好。
样本 0 的 Router 与 Router-off 伪距离相同，可最后听作近似持平对照。

## 记录听感时只需回答

- Router 是否比 Router-off 更容易听清？
- 是否出现额外断续、吞字、变调或机械声？
- 如果无法区分，直接写“差不多”。
