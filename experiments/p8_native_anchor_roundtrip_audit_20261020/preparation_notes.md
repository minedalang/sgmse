# Software preparation: native anchor roundtrip audit

Prepared only; no real model, checkpoint, PCM/header or HTTP access occurred during preparation. The script has a strict authorization gate before any protected model/audio read. Missing or mismatched authorization fails before STARTED. Once STARTED exists there is no retry. Root must issue root_execution_authorization.json with status authorized_once and exact fields: config_sha256, code_sha256 (audit.py hash string), manifest_sha256, source_checkpoint_sha256, core_sha256 (absolute source mapping), source_registry_sha256 and old_baseline_sha256.

The frozen config is JSON-form YAML. audit.py reads it with stdlib JSON and normalizes aliases in memory only. The source loader and EMA materialization follow the successful N/D loader, without optimizer, enable_backend_training, gradients, EMA updates or train-mode transitions. Every parameter is frozen. Eight selected original S/X pairs are the only PCM decodes; noise1_path is ignored. Runtime first hashes the sixteen source files and source checkpoint, then records post hashes. Manifest stays unchanged. Source checkpoint is loaded once and never copied or written.

Each case uses a common center crop of length32640 and original Noisy peak; clean and noisy normalization matches the existing CPEL crop routine. One frontend.forward_transformed_spec call yields raw transformed complex anchor. Its exact frontend.spec_to_waveform inverse yields the normalized waveform. Public enhance receives [1,L] physical frontend waveform and physical original Noisy; this shape is asserted explicitly. The instance get_pc_sampler wrapper records the actual public anchor and partial Score function's y_cond, calls the original sampler, and is restored in finally. The ScoreModel.enhance return profiler records the actual norm and T_orig without modifying output and is restored immediately. Existing dnn forward hook counts actual Score calls. CPU and CUDA RNG are reset separately before each branch.

The expected public anchor uses frontend.spec_to_waveform followed by model._sgmse_stft and existing pad_spec. Runtime verifies both modules' n_fft, hop, compression settings and identical window tensor, along with expected source frames, sample rate and topology. No custom inverse or replacement public enhancement is used. Raw branch preserves the CPEL sampler arguments. Both outputs are compared on normalized physical waveform scale without clipping or PCM serialization. Only scalar errors and tensor shape/dtype/hash descriptions are retained; zero raw/public difference is a valid complete result.

Interface tolerances gate actual-versus-expected public anchor and noisy condition. Raw-versus-public differences and old initial baseline sanity are measured outcomes, not success gates. Baseline matching checks both utt and original dev index/crop. A baseline numerical mismatch is recorded without retry. An interface mismatch, nonfinite value, shape error or budget failure stops the run and preserves partial metrics. The bounded run includes imports, source hashing and loading, all sixteen backend calls and source protection. There is no new validator/preflight run, quality metric, ASR, waveform/spectrum artifact or checkpoint artifact.

Interpretation: this measures current raw-spectrum versus public-waveform interface equivalence. Compression epsilon and STFT consistency projection can produce differences. Nonzero error does not establish a normalization bug, phonetic damage, successful mechanism or expected benefit. Current code does not establish the original300k historical training interface. Existing VB32 hooks already verified common Noisy normalization; this audit does not repackage that as a new finding.

Preparation verification uses stdlib AST parsing and metadata-only checks. Do not execute audit.py before Root authorization.
