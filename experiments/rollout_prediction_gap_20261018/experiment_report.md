# Reverse-rollout versus analytic-forward x0 prediction gap (2026-10-18)

## Question

Does the fixed Score model make substantially worse clean `x0` predictions on states generated by its own reverse sampler than on analytical OUVE states of the type used during training?

## Protocol

- Four existing P7 development utterances, not the official test set.
- Fixed 80k checkpoint with EMA; PC reverse diffusion, `N=30`, no corrector, `snr=0.5`.
- Capture each reverse pre-predictor state `x_t`.
- At the same time `t`, independently sample an analytical forward state from `OUVE(clean, Y_pre, t)`.
- Run the same Score model on both states and convert the score to an OUVE clean `x0` estimate using the configured SDE weights.
- Compare normalized complex-spectral MSE to clean. No training, output WAV, or checkpoint write.

## Results

The initial four-utterance smoke and a fresh-CV replication were completed. The fresh-CV set contains 8 utterances from 8 speakers not present in the P7 manifest.

| set | rollout x0 NMSE | analytic-forward x0 NMSE | rollout minus forward | positive utterances |
|---|---:|---:|---:|---:|
| P7 smoke, 4 utterances | 0.8021 | 0.2147 | +0.5874 | 4/4 |
| fresh CV, 8 utterances | 0.5140 | 0.1356 | +0.3785 | 8/8 |

The fresh-CV per-step difference peaks around `t=0.73–0.77` (mean about `+0.61`) and remains positive through the final step (mean about `+0.30`). Full per-step values, hashes, and the fresh manifest are stored in this directory.

## Interpretation boundary

A positive rollout-minus-forward error gap is now replicated across 8 fresh-CV utterances and qualifies a bounded rollout-aware post-training pilot. It still does not prove that the gap causes final PESQ/DNSMOS degradation or that Corrective Forcing will help. The next intervention must detach the generated state, train only a declared backend parameter subset, preserve an exact no-op baseline, and use fresh-CV final audio metrics with a predeclared stop rule.
