# 执行前固定的判读方案

只回答自然5243已有人耳/d/候选对局部direct noisy语音分量的敏感性。原生门必须先通过；本实验不评价新增强算法，不证明原始noisy独立可辨。

主要观察量为原固定帧[35,36)的d后验；辅助量为原邻域[25,46)的d最大/平均后验、该邻域内最大位置及完整自由CTC序列。所有窗口均沿用已有协议，不重新对齐或更改阈值。输出是原18.75–20.75秒PCM片段；记录每臂clip均值/RMS/std和特征提取归一化描述，避免把全局归一化或识别器上下文响应当成确定的声学身份变化。

每臂令Δ=P_native(d)−P_arm(d)，完整报告target、left、right；可以描述Δ_target−max(Δ_left,Δ_right)，不赋予总体显著性或成功阈值。单事件、经选择且OOD，不做bootstrap、p值、恢复率或总体胜率。

- 目标移除比两个能量匹配位置对照均更降低fixed及nearby支持，才保留“该位置输入对这次目标响应特别重要”的候选；它仍不等价于提取了孤立/d/，也不触发训练。
- 若只有单帧下降、邻域仍有强目标，优先解释为时间/代理敏感性，不能记为音素删除。
- 若位置对照同样影响目标，说明上下文或非局部条件响应也有作用，不把结果写成目标音素证据特异性。
- 若三种移除均几乎无响应，只能说明当前干预未建立必要性；不能证明noisy没有信息或后端从不使用noisy。

同时保留目标窗、两对照窗及其余输出相对native的波形差异，不把谱/波形变化直接当作内容对错。若出现额外发音候选，区分残噪、摩擦样伪影和真实内容插入，不能沿用中央标签代替全片段判断。

四臂全部完成后结束本项，无论方向不扫seed、强度、边界或另挑对照。任何原生、源哈希、随机状态、归一化或采样门失败则停止并记录。人耳仅在有明确新内容候选时提出少量可选核验，不等待答复开展独立工作，也不重做已完成的VCV五例。
