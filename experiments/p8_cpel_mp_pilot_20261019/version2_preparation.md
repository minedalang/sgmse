## Actual code changes

- `gradient_budget.py` composes returned first-order gradients. Every M/P step uses the same four Score forwards and two `autograd.grad` traversals: `gM=grad(native+aux)` and `gp=grad(pair)`. Finite nonzero norms and active pair give `eta_candidate=min(100,.01*norm(gM)/norm(gp))`, with no positive lower floor. Zeros/inactive give0; nonfinite is a terminal error. P applies candidate, M applies0. Both-None remains None; pair-nonNone/M-None asserts graph-subset failure; M-nonNone/pair-None preserves M. Raw norm/cosine, candidate/applied eta and effective candidate/applied budgets are logged before shared clip1/Adam/EMA. Scalar logging is a detached-eta surrogate, **not a fully differentiated static lambda objective or an Adam update budget**. Intrinsic Fourier W remains frozen and outside optimizer/EMA arithmetic.
- Runner `--config config_v2_draft.yaml` selects the reviewed v2 document; the default is this same filename. Root authorization and initial-base cache bind the **actual selected config SHA** and all four source files (`run_pilot`, `loss_helpers`, `editing`, `gradient_budget`). Old v1 configs cannot silently execute the v2 rule. Canonical config is not overwritten by this preparation.
- Codec diagnostics retain the old normalized relative-RMS strict.001 column. Independently, physical-amplitude float64 samples are tested elementwise against nearest `.5*sum(q)` and general `sum(q)` bounds, with `q=2^(1-bits)` for known integer PCM16/24/32 and numerical tolerance1e-12. Format, endpoints, exceed counts, bounds and compatibility are recorded. Unknown codec, crop endpoints or incompatible general bound do not enter the noise-response packet. General-compatible/no-endpoint records may describe the **stored noise-instance perturbation response even when strict fails**, not verified pure noise, a true negative, FPR or hallucination rate. `processing_chain_verified=False` remains explicit. Historical strict43pass/21fail results are not changed or withdrawn.
- Added one precision-matched heldout packet. The same original Tukey event center and Gaussian seed/time/both parents are reused. Both clean and both noisy physical endpoints receive the same fixed PCM16 nearest/ties-to-even float64 quantizer before dividing by the original X1 peak. Out-of-code-range/nonfinite quantization is unknown, never clipped into validity. Endpoint and invalid coverage are recorded. Actual quantized clean-spectrum difference is recomputed. Physical/compressed target changes and both branch residual changes are recorded; common noise after quantization is **not** asserted. Only this diagnostic adds up to four Score calls per dev row; normal deployment PC N30 is unchanged. Training Hann edits are unchanged.
