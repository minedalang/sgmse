Prepared only. No evaluation, model import, real PCM/header read, checkpoint/tensor storage read or HTTP request occurred during preparation. eval_public.py accepts the Root frozen JSON-form config.yaml directly. Authorization must have status authorized_once and exact config_sha256, code_sha256 (single script hash), registry_sha256, source_checkpoint_sha256, terminal_sha256 mapping N/D, core_sha256 mapping and historical_metrics_sha256 mapping N/D. Protected file content reads start only after this gate. STARTED prevents any retry.

The source strict JointWaveScpDataModule checkpoint loader, one eval(no_ema=False) materialization and offline/native-PATH/CUBLAS environment follow the successful audit and N/D implementations. All parameters are frozen. No subsequent eval/train transition is called. A CPU clone of the complete source dnn state provides source topology and the source evaluation state. Each existing N/D dnn-only packet is loaded once on CPU with weights_only=True and checked for schema, arm, source checkpoint hash, exact keys, shape, dtype, finite tensors and unchanged intrinsic W. Each arm is injected with strict dnn.load_state_dict; canonical name/shape/dtype/byte digests must equal its CPU state immediately after injection and after the arm. Source, N and D are all evaluated without choosing one.

The complete original64 registry is consumed in original order. Each clean/noisy pair is decoded once, commonly center cropped/padded to32640, and normalized by the original Noisy peak. The source frozen frontend is run exactly64 times. Its exact spec_to_waveform output is returned to physical amplitude and cached on CPU as [1,L], together with physical Noisy and normalized clean. These three inputs are hashed and checked against mutation before each of the192 public calls; their CPU cache is never exported. There are no edits or noise1 reads.

The original model.enhance public API supplies actual sampler anchors and Noisy conditions. The instance get_pc_sampler observer retains only tensor descriptors and explicit settings, invokes the original sampler, and records actual NFE. A dnn forward hook independently counts actual Score calls. The successful ScoreModel.enhance return profiler observes actual normalization and length and is immediately restored; no output is changed. The exact cached inputs, original dev-index seed, actual sampler anchor/condition descriptors and settings must match across source/N/D. Each call must use actual norm equal to its original Noisy peak, length32640, NFE30 and Score30. There is no ideal roundtrip equality tolerance gate, and the older failed7 audit is unchanged.

Public returned physical float32 output is divided by its original Noisy peak. MSE uses the same float64 difference as N/D. SI-SDR uses the same centered dot-product target projection. STOI uses extended=False and PESQ uses16000/format wb with the unchanged installed implementations and their standard internal processing. No external clipping, PCM serialization or independent gain normalization occurs. Undefined or unavailable metrics retain null plus errors; rows are never removed or replaced. Summary includes all three absolute means/counts and matched D-minus-N, N-minus-source and D-minus-source differences/counts.

Persistence/resource failures mark the result failed and retain partial metrics where storage permits. Only scalar metrics and descriptors are written; no audio, spectra, cached arrays, optimizer or weights are saved.
