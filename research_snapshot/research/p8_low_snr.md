# P8：极低 SNR 下的真实内容保真与生成错误

> **状态**：第一优先级科学问题；既有诊断和多组人工反馈已完成，但音素可恢复性、模型纠错机制及总体发生率**仍未证实**。此文件描述研究逻辑，实际数据见 [evidence_summary.md](evidence_summary.md)，当前执行权限仍以 [总纲](../research_plan.md) 为准。

## 1. 系统与三种不同失真

单通道观察 `X=S+N`；原生前端 `Y_pre=F(X)`，后端 StoRM Score 接收 `[x_t, X, Y_pre]`，OUVE 的初态、漂移中心均围绕 `Y_pre`。现有 80k 权重使用 `mode2_include_noisy_main=true`，未启用 selector/cross-attn/FiLM；因此不存在“后端完全没看 Noisy”的结构事实。

| 类别 | 用户关心的现象 | 尚需区分的解释 |
|---|---|---|
| **H8-E：前端吞音未补回** | `/k/`、`/d/` 等弱辅音在 `Y_pre` 不明显，后端把剩余音节修得圆润，但原音节没补回 | Noisy 有信息而后端没用足；Noisy 难以辨识；两者并存 |
| **H8-A：后端错误补音** | `Y_pre` 没有额外语音，后端在局部出现异常、疑似语音样结构 | 生成先验补全、残噪、非局部影响、条件失配，不能只凭人耳或 CTC 下定论 |
| **H8-C：正常音质收益** | 后端改善残噪、连贯度和音节质量 | 真实改善可与个别内容损伤并存，不能只抓坏样本 |

明确分开：**物理成分存在**、**Noisy 可辨识正确音素**、**当前后端确实提取并正确恢复**。同样，“更响、更像辅音、更自然”不等于“目标音素正确”。

## 2. 当前能说与不能说

1. 原生 Noisy 直接分支确实影响后端生成，包括非局部效应；并非完全被忽视。但是，`F(S+N)` 锚点与 `N` 条件的交叉干预通常属于 OOD，不能把响应当正确补音或否决的因果证据。
2. 既有 VCV 在某些固定身份上发生前后端修正或损伤；新说话人 Router 身份净收益未复现。名义 `-6 dB` 为 2 秒载体 SNR，实际语音支撑区约 `+0.867 dB`，更不能外推为自然 DNS `-18/-20 dB` 弱辅音。
3. 用户的自然 `/d/` 正候选（file-id 5243）必须保留；但目标 Noisy 移除后 CTC 后验与人耳强度方向不同。不能说“后端从不补音”，也不能说“去除 Noisy 证明必要性”。
4. 单个 VCV 尾部 `/s/` 样现象在 Clean 支撑外，且可能是高频噪声样伪影；不预先记为真实生成的 `/s/`。同理 B 开头现有 CPU 增能不等于错误音素的精确身份。
5. VoiceBank pilot 提供了有发布者原文的小规模内容参考，但仅四句、两位说话人，Whisper WER 是识别器代理。用户听到 A 的音质正收益与 B 的风险必须共存。

**条件利用先例复核**：[定向审查](../../research_memos/p8_condition_utilization_priorart_20261019.md)纠正DOSE旧简称：替换的是中间x_t而非Noisy；直接沿用旧DSM噪声监督有不同最优解。条件会影响输出不等于充分/正确利用，也不能由吞音单独诊断坍缩。现有条件传递/state-drop/预测引导已有先例，当前不新增模块或训练；内容证据与匹配过程仍是下一验证重点。

## 3. 原有研究支线与进展

### P8-0 / P8-1：数据与人工内容

- P8-0 只读覆盖审计已完成：train/CV 约 `10,800/1,200` 条、`90/10 h`、16kHz；名义文件名 SNR `-20` 至 `-6 dB`。真实局部辅音 SNR 暴露仍 unknown，CV 有一位 speaker 跨 split。本地 DNS `text` 是 `dummy`，不能拿它做真实 WER。
- 第一轮 `noisy / Y_pre / Router-off / Router / clean` 音频和人工反馈已有记录；现有旧 DNS 个例缺可信独立原句文本及人工音素边界，不能形成正式总体人工 WER。VoiceBank 新 pilot 仍不够代表性。
- 未来若申请新确认实验：先冻结未反复使用的内容/说话人/噪声，至少两名独立听者盲转写，以内容判断先于自然度和清晰度评分，分别报告替换/删除/插入与听感，ASR 只辅助。

### P8-Q：Noisy 中辅音证据是否能辨识

- **Q-A（已做探索性代理）**：10/20 ms 局部时频线索、CTC 强制目标、固定时间后验都完成，但同一识别器存在严重边界漂移；低目标后验不是信息论不可辨，能量或 token 数也不是音素身份。
- **Q-B（条件）**：提高固定噪声中目标辅音局部贡献，只用于判断受控输入的可辨识阈值，不能把加能后恢复算原始 Noisy 的成绩。
- **Q-C（条件）**：在**不修改原始 Noisy**的情况下，使用真实已知目标身份或独立人工确认内容，测真实内容恢复和错误新增，避免仅看自然化。
- **Q-D（受控 VCV 已有多轮）**：同噪声换真辅音、同真辅音换噪声；已有作者标称身份的 clean 校准、固定噪声 input 与前后端实验、不同 speaker 复验。其受控性强于旧 DNS 的伪文本，但 VCV/padding/SNR/识别器均限制外推；不要重复已结束的原始 VCV 搜索。

### P8-M：正常 `Y_pre` 音节局部抹除（已停止）

5243 局部 `Y_pre` 衰减/抹除在多 seed 下使 SI-SDR/STOI 下降；它是破坏 `Y_pre=F(noisy)` 训练对应关系的 OOD 反事实，没有显示无代价地从 Noisy 补音。保留负结果，不作为下一轮新实验。

### P8-C：Noisy 约束 vs 条件冲突（归档，未运行四格）

既有第五例：保留原生锚点与 RNG，只从直接 Noisy 条件去掉整段已知语音分量，即使目标尾部条件逐样本相同仍改变尾部生成。这提示跨时间条件敏感，但不能分清：

- **H-C1**：Noisy 中真实语音上下文对错误补全有声学限制作用；
- **H-C2**：原生前端锚点与人为 Noisy 失配引发 OOD 冲突；
- **H-C3**：语音整体移除、信号统计或模型非局部动力学变化。

预备设计过 2×2：锚点 `F(S+N)/F(N)` × Noisy 条件 `S+N/N`。即便对角格也不天然是训练域内；换锚点改变 OUVE `x_T` 和漂移，跨行只能共享底层 Gaussian `z`，不能强制相同 `x_T`。冲突格的参考目标不是自然唯一确定的；该四格**未获得新执行许可**。这只是机制诊断，不等于下面 P8-V 的候选声学验证算法。

### P8-N / P8-R（均未开训）

- **P8-N**：合法的 noisy-centered 扩散第二视角，与 `Y_pre`-centered StoRM 比较是否存在**真实音素正确性**互补。冻结 StoRM 上直接换中心/初态不等于合法第二模型。
- **P8-R**：定位真实过抑制，再定向提取 Noisy 线索。普通 mask、能量/局部 SNR/条件门控不足以自称原创；先证明风险预测优于简单基线、输出真实音素收益和新增错误控制。
- **P8-V**：独立的“候选存在/不存在”声学证据验证与三态审查；核心设计见 [p8_v_counterfactual.md](p8_v_counterfactual.md)。它不是 P8-C 的重命名，也不是 P8-R 的简单风险门。

## 4. 进入新实验前需要回答

**新增用户方案 P8-I（准备，非结果）**：[原始Noisy局部声学可辨识性](p8_noisy_identifiability.md)把“结构/事件/具体身份”分层，拟在train内同noise构造保留/削弱对，未来比较D0–D4并校准unknown。先准备元数据、配对/残差和无泄漏门；不立即训练探针或调用StoRM。自动编辑标签不是实际音素金标，D3增益不是新增独立信息；此门仅服务相应局部/CAEG主张，不抹掉下面有限句级诊断的独立性。

**Lead复审与后续完成状态**：强音素/双向证据门约束相应强主张，不是所有句级代理诊断的前置条件；标注/parser支线已收口。此前所写“只批准8句metadata、32条件模型未批准”是历史阶段，现已由唯一运行与独立验证覆盖：8句/4speaker、32条件headroom测量完成并关闭，结果受ASR失效与speaker异质性混杂，不升级verifier/selector。随后方向MSE、旧四seed缓存和估计对象审查也已收口；没有批准新的读出/协方差/Jacobian/训练。最新数字见 [证据摘要](evidence_summary.md)，估计对象边界见 [专项审查](../../research_memos/p8_estimand_readout_audit_20261019.md)。旧设计与独立批评在项目根 `research_memos/p8_validation_gate_reassessment_20261019.md`、`p8_validation_gate_critic_20261019.md`，不以旧“待执行”状态重启任何实验。旧实验停止边界不变。

1. **标注依据**：是真实音素身份和人工听感，还是单一 CTC/ASR 代理？没有独立身份就不能称“恢复正确辅音”。
2. **输入可辨识性**：同噪声不同真实音素有没有可重复的区分证据？低识别器置信度只能称“当前识别器不支持”，不是“Noisy 不含信息”。
3. **匹配条件**：原生归一化、锚点、noise 分量、时序、随机数和 OUVE 过程是否有条件冲突或 OOD？
4. **双向损失**：恢复真事件与错误新增两个方向同时衡量；只压掉不确定高频不能算成功。
5. **独立性**：旧探索集、被人工反复听过的片段、冻结官方 DNS 测试集不可再用于新方法的确认或调参。
