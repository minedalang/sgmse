# Published research snapshot

This directory backs up the external `/data/research_plan.md`, `/data/research/` and user research objective for cloud review. **It is a publication snapshot, not a second live execution entry.** On the original environment, continue to use `/data/research_plan.md` and `/data/AGENTS.md`.

Start with [research plan](research_plan.md), [CPEL topic](research/p8_paired_evidence_training.md), or [objective](goal.md). Only local Markdown navigation links were remapped; source/published SHA256 are in `snapshot_manifest.json`. Original configurations, metrics, command traces and failures remain under the project experiment directories.

Model weights, source/derived audio, numerical signal caches, runtime environments and download archives are intentionally not versioned. A published authorization JSON records historical execution only; it does not authorize a new run on another machine. Prepared long-run code/metadata is not evidence that 100k training has started or completed.
